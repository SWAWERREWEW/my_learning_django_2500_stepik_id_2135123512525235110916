93 day = 14.4 Dockerfile. Создание образов

При разработке нужно создать контейнер, поместить в него весь сайт, переместить этот контейнер на dockerhub и
cклонировать его на сервер, вместо репозитория на github

В Dockerfile (файл с заглавной буквы и без расширения) содержит команды по созданию нового образа для сайта

Можно скачать visual studio code
https://code.visualstudio.com

Необходимо создать первый простой образ
В нём должна быть
команда запуска
python программа
Интерпретатор python
Микро ОС

➕📁🛠💾
Был создан файл
# docker/for_first_image.py
import time

total = 100
count = 0
while count < total:
    count += 1
    print("kikidon: " + str(count))
    time.sleep(1)

➕🛠💾
Был создан файл
docker/Dockerfile
FROM python:3.12-alpine
WORKDIR /python-app
COPY . .
CMD ["python", "for_first_image.py"]

Команда для создания образа на основе Dockerfile
docker build путь\к\Dockerfile\ -t имя_образа

Был создан и произведён запуск контейнера
docker run -it --name first_conteiner first_conteiner:first_conteiner

Запуск по команде не позволит увидеть вывод, потому что нету буферизации
docker start -i first_conteiner

Добавление буферизации

💾🛠
Был изменён файл
docker/Dockerfile
FROM ...
ENV PYTHONUNBUFFERED=1
WORKDIR ...
...

💼⚙➕💾🛠
Создание нового обновлённого образа
docker build . -t first_image:0.2

➕🛠📦
Создание нового обновлённого контейнера
docker run -it --name first_container first_image:0.2

🚀📊
Повторный запуск с выводом в терминал
docker start -i first_container

Пересборка образа осуществляется такой же командой, какой создается
