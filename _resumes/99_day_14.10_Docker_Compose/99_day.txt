Параметр depends_on указывает на службу, после которой должен начаться запуск текущей службы

🛠💾 Был изменён файл
first_db_image\compose.yaml
services:
  ...
  # docker run --rm -d --network dbnet --name adminer_container --link postgres_container:db -p 8080:8080 adminer
  service_adminer:
    image: adminer
    container_name: adminer_container
    ports:
      - "127.0.0.1:8080:8080"
    links:
      - "service_load_db:db"
    networks:
      - dbnet
    depends_on:
      - service_load_db
networks:
...

Теперь происходит автоматический запуск сразу двух контейнеров

http://127.0.0.1:8080/?pgsql=db&username=postgres&db=mydb&ns=public&select=women

http://127.0.0.1:8000/
