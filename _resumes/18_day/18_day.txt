18 day = 3.2 Создание и запуск файлов миграций

Для создания таблицы нужен файл миграции
Миграция это скрипт для применения актуальных изменений (и возвращения к старой версии)

Файлы миграции создаются автоматически (кажется каталог sitewomen\women\migratios стоит добавить в .gitignore)

Создание файла миграции по команде
python manage.py makemigrate

Создание запроса по созданию изменений, зафиксированных в файле 0001_initial.py
python manage.py sqlmigrate women 0001

Однако сама таблица не была создана. Было зафиксировано создание лишь модели.
Для создания таблицы модели нужен название приложения, номер файла миграции и SQL запрос, который генерируется с
помощью команды

python manage.py sqlmigrate (название приложения) (номер миграции)

например
python manage.py sqlmigrate women 0001

(.venv) D:\...\sitewomen>python manage.py sqlmigrate women 0001
