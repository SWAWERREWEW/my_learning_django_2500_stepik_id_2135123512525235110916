Распаковка с помощью двух звёздочек **form.cleaned_data не получается потому, что вы пытаетесь использовать её внутри
функции print(), которая её просто не поддерживает.Оператор ** в Python осуществляет распаковку словаря в именованные
аргументы (keyword arguments) функции.Как это устроено в PythonОдна звёздочка * распаковывает элементы (ключи словаря)
по очереди через запятую:pythonprint(*form.cleaned_data)  # Превращается в: print('title', 'slug', 'content')
Используйте код с осторожностью.Функция print() умеет принимать бесконечное количество позиционных аргументов через
запятую и просто выводит их на экран.Две звёздочки ** превращают словарь в именованные аргументы:
pythonprint(**form.cleaned_data) # Превращается в: print(title='Значение', slug='url', content='Текст')
Но у встроенной функции print() нет параметров с именами title, slug или content. У неё есть только свои стандартные
параметры: sep, end, file и flush. В итоге Python выдает ошибку TypeError: 'title' is an invalid keyword argument for
print().Так как у вас весь код обёрнут в try ... except, Python ловит эту ошибку TypeError и вместо вывода в консоль
сразу уходит в блок except, где добавляет ошибку в форму.Зачем на самом деле нужны две звёздочки ** в DjangoОператор **
нужен не для вывода на экран, а для автоматической передачи данных в метод создания записи в базу данных
Objects.create().Вместо того чтобы вручную прописывать каждое поле:pythonWomen.objects.create(
    title=form.cleaned_data['title'],
    slug=form.cleaned_data['slug'],
    content=form.cleaned_data['content']
)
Вы можете использовать как раз те самые две звёздочки, потому что класс Women (ваша модель) принимает именно такие
именованные аргументы:python# Вот здесь две звёздочки отработают идеально!
Women.objects.create(**form.cleaned_data)
