Тип связи Many To Many
Связи таблиц по принципу: Один студент может учиться у несколько преподавателей, а преподаватель может обучать
несколько студентов. Есть две таблицы, но для реализации такой связи будет автоматически создана третья. С
идентификаторами обоих таблиц. Три поля: идентификатор записи, какой-либо идентификатор из первой таблицы, какой-либо
идентификатор из второй таблицы.

class TagPost(models.Model):
    tag = models.CharField(max_length=100, db_index=True)
    slug = models.SlugField(max_length=150, unique=True)

    def __str__(self):
        return self.tag

from women.models import Women, TagPost
TagPost.objects.create(tag='Крутые',slug='krutye')
TagPost.objects.create(tag='Средние',slug='srednie')
TagPost.objects.create(tag='Прикольные',slug='prikulbnye')
Women.objects.get(id=1).tags.set(TagPost.objects.all())

Для первой записи можно приписать несколько тегов из второй таблицы с помощью команды set
Была выбрана первая запись таблицы Women, потом привязанная таблица TagPost (Название переменной с объектом
models.ManyToManyField), команда для добавления и записи из второй таблицы TagPost (в данном случае были выбраны все).

Для удаления привязанных записей к выбранной можно использовать команду remove вместо set
Команда, идентичная команде set есть команда с добавлением только одной записи это add

Можно узнать к какой записи привязан выбранный тег (В данном случае названием related_name='tags')
(В данном случае тег выбран по полю id)
Сначала выбранный тег, потом менеджер связи, потом записи из таблицы, к которой привязана таблица с тегами
TagPost.objects.get(id=1).tags.all()
Выбран третий тег, потом менеджер связи, потом к каким записям тег привязан среди записей под номероми 1 и 3
TagPost.objects.get(id=3).tags.filter(id__in=[1, 3])
Выбран третий тег, потом менеджер связи, потом к каким записям привязан тег среди одной записи
Тег не привязан к выбранной в конце записи, то будет ошибка
TagPost.objects.get(id=3).tags.get(id=1)

🛠➕📊💬
Второй тег добавляется ко второй записи
TagPost.objects.get(id=2).tags.add(Women.objects.get(id=2))

🛠📊➕💬
Добавление тега "Прикольные" для третьей записи
Women.objects.get(id=3).tags.add(TagPost.objects.get(tag='Прикольные'))

Можно создать новую запись и добавить к второй тег (Команда раздепена из-за слишком большой длинны)
Рекомендуется использовать переменные для избежания повторного обращения к базе данных.
Women_new = Women.objects.create(title='new', content='no', is_published=0, slug='NoName', cat_id=1)
❌Неправильно (Возможна ошибка при поиске по полю title (оно может повторяться) и дополнительная нагрузка не сервер при
повторном поиске созданной записи)
Women.objects.get(title='new').tags.add(TagPost.objects.get(id=2))
✅Правильно (Ссылка на созданный объект сохранена для отсутствия надобности искать его повторно, избежав ошибки при
поиске)
Women_new.tags.add(TagPost.objects.get(id=2))
