73 day = 10.1 Протокол OAuth 2.0. Установка пакета Python-Social-Auth

В мире есть возможность авторизоваться на сайтах через другие аккаунты.

Например, на не связанном с google сайте для творчества можно зарегистрироваться через аккаунт google
Этот метод называется социальной аутентификации или авторизации через социальные сети.

Для реализации авторизации через социальные сети нужен протокол OAuth 2.0 (Open Authorization)
Ход его работы начинается с кнопки авторизации через социальные сети на сайте для творчества

💬🚀📝🏠 Сайт для творчества отправляет запрос на аутентификацию
✅🚀📦🗝 Социальная сеть выдаёт разрешение на аутентификацию

💬🚀🗝🏠 Сайт для творчества использует разрешение на аутентификацию
✅🚀💾📦 Социальная сеть выдаёт токен доступа

💬🚀💾🏠 Сайт для творчества использует токен доступа для получения данных
✅🚀📦📊 Социальная суть отправляет все нужные данные ✅💼🎉

❌⚙🛠💾📁
Реализации всего протокола вручную не будет, но маленькие детали будут меняться в зависимости от социальной сети

📝💼💾
Для использования протокола нужны технологии или библиотеки
Django-Allauth
Dajngo-Social-Auth
Python-Social-Auth
