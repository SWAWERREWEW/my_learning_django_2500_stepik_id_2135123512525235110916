Выбор первой записи по индексу🔍📦📁
Women.objects.all()[0]

При выполнении команды🔍📊📐
w = Women.objects.all()[:3]
Обращения к базе данных не происходит из-за принципа "ленивого запроса", однако оно происходит в момент обращения к
самой переменной. Над переменной можно производить операции перебора через цикл for
for i in w:
    print(i)

Если таблица огромная, существует фильтр🔍📦
Women.objects.filter(title='Анджела')

Для фильтра чисел необходимы методы💼📊📖
Сравнение больше или равно
.атрибут__gte=число
Сравнение больше
.атрибут__gt=число
Сравнение меньше или равно
.атрибут__lte=число
Сравнение меньше
.атрибут__lt=число

Пример
Women.objects.filter(pk__gt=2)

Метод для поиска записей с фрагментом текста🔍📖📐
.атрибут__contains='фрагмент'

Пример
Women.objects.filter(content__contains='а')
Или без учёта регистра, хотя это не сработает из-за ограничений самой базы данных📝❌
.атрибут__icontains='фрагмент'

Перебор вариантов. Вывод записей с определёнными значениями из списка.🔍📝
.атрибут__in=[число, число, и т д]
Women.objects.filter(id__in=[1, 3])

Есть возможность ставить несколько условий📦📝📊
.filter(условие, условие, и т д)

Women.objects.filter(content__contains='а', id__in=[1, 3])

Можно ознакомиться с документацией🔍📖📊
docs.djangoproject.com/en/4.2/ref/models/querysets/#field-lookups

Существует возможность выбрать все записи, кроме определённых или выбранных по условию
.exclude(условие)
Будут выведены все записи, кроме записи с id=2
Women.objects.exclude(id=2)

Существует метод get, который возвращает либо ошибку при получении нескольких записей, либо возвращает одну запись.
Ошибка
Women.objects.get(id__in=[1, 3])

Первая запись
Women.objects.filter(id__in=[1, 3])[0]
