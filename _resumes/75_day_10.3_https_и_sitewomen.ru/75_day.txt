Для поддержки протокола https нужен реальный сервер и библиотеки
Расширение RunServerPlus из библиотеки Django Extensions поможет в тестировании и отладки, однако отладчик содержится
в библиотеке Werkzeug, а библиотека pyOpenSSL симулирует слой для https

🛠💾
Был изменён файл
sitewomen\req.txt
...
django-extensions==3.2.3
werkzeug==2.3.7
pyOpenSSL==23.2.0

🛠📝
Была использована команда
pip install -r req.txt

🔍📝
Можно было использовать команды
pip install werkzeug==2.3.7
pip install django-extensions==3.2.3
pip install pyOpenSSL==23.2.0

Нужно подключить библиотеку django-extensions в настройки

🛠💾
Был изменён файл
# sitewomen\sitewomen\settings.py
...
INSTALLED_APPS = [
    ...
    'django_extensions',
]

Команда для запуска
python manage.py runserver_plus --cert-file cert.crt
