Необходима сортировка и кликабельность надписей у каждой записи.

💾🛠
Был изменён файл sitewomen\women\admin.py
...
@admin.register(Women)
class WomenAdmin(admin.ModelAdmin):
    list_display = ("id", "title", "time_create", "is_published")
    list_display_links = ("id", "title", "time_create", "is_published")
    ordering = ["time_create", "title"]

# Register your models here. 
# admin.site.register(Women, WomenAdmin)

✅🚀
После запуска все надписи каждой записи стали кликабельными и с переходом на подробную информацию о записи с помощью
переменной list_display_links, а также записи стали сортироваться по полю time_create с помощью переменной ordering.
Причём сортировка по двум полям просто происходит последовательно. Сначала по первому полю, потом по второму при
записях с одинаковыми значениями в первом поле.

Отображение поля is_published в таблице происходит неверное и противоречит действительным данным по причине того, что в
файле sitewomen\women\models.py
во время определения поля происходит присваивание ему числового значения 0 и 1 вместо булевого Ложь и Правда из-за
ограничений django. Для исправления было использовано преобразование чисел в значения на примере
lil = (1, 0, 1, 1, 1, 0)
print(tuple(map(lambda x: True if x == 1 else False, lil)))
# Вывод (True, False, True, True, True, False)

💾🛠
Был изменён файл sitewomen\women\models.py
class Women(models.Model):
    ...
    is_published = models.BooleanField(choices=tuple(map(lambda x: (bool(x[0]), x[1]), Status.choices)),
        default=Status.DRAFT, verbose_name="Стутус")
    ...
