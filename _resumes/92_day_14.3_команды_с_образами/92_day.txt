➕📦📝
Создание контейнера с выбранным именем
docker run --name kikidon hello-world

🚀📊📶
Запуск контейнера
docker start kikidon
Запуск с выводом контейнера
docker start -i kikidon

❌⚡
Остановка
docker stop kikidon

❌🥀☠📶
Убийство при отсутствии возможности остановить
docker kill hello-world

📝🚀📊
Запуск контейнера в фоне с выводом в терминале. В данном случае просто запустится python.
docker run -i -t python:3.12-alpine

📦➕📝
Создание нового контейнера с названием "it-python" на основе образа Python 3.12 Alpine
docker run --name it-python -it python:3.12-alpine

Код 137 означает принудительное завершение контейнера

❌📦
Команда удаления контейнера
docker rm gallant_goldberg

❌📦💥
Удаление всех неработающих контейнеров
docker container prune

❌📊
Удаление образов
docker rmi hello-world

Если контейнер, то нельзя удалить образ

➕📦❌
Команда по созданию одноразового контейнера
docker run --rm python:3.12-alpine

Помощь
