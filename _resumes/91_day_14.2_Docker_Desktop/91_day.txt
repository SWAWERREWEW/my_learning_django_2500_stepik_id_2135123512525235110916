Установка на Linux
Самый нативный вариант установки Docker под ОС Linux, для которой он изначально и разрабатывался. Здесь также можно установить целиком Docker Desktop, и ниже показаны поддерживаемые платформы:

https://docs.docker.com/desktop/setup/install/linux/

При этом обратите внимание, что Docker Desktop будет работать в своей изолированной оболочке с еще одной облегченной ОС Linux так же, как это происходит под Windows и Mac. Это сделано для гарантии единообразного поведения данной программы на разных ОС. Но, так как докер все же разработан для Linux, то здесь имеется возможность отдельно устанавливать его компоненты, в частности Docker Engine и Docker Compose. Это, конечно же, несколько увеличивает скорость работы докера под Linux. Для других ОС такой возможности нет. Там можно использовать только Docker Desktop.

Установка на Windows
При установке докера на ОС Windows возможны также два варианта в зависимости от используемого процессора. Однако лучше все же использовать инсталлятор для машины x86_64. Далее перечислены системные требования. Лучшим вариантом будет использование WSL версии 2. WSL – это ядро ОС Linux для Windows. Как мы с вами говорили на прошлом занятии, компоненты Docker разработаны и работают под Linux, т.к. большинство серверов используют именно эту ОС. И чтобы иметь возможность запускать эти же компоненты под Windows создается либо оболочка, взаимодействующая напрямую с ядром Linux, то есть, с модулем WSL, либо создается полноценная виртуальная машина с ОС Linux и взаимодействие выполняется посредством гипервизора (Hyper-V). Это несколько более нагруженный и медленный вариант использования Docker на компьютере. Поэтому мы будем ориентироваться на использование ядра WSL.
