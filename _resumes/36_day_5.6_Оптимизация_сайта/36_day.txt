36 day = 5.6 Оптимизация сайта с Django Debug Toolbar

Критерии оптимизированности сайта
- Скорость работы приложения
- нагрузку на СУБД (частота и сложность запросов)
- Корректность возвращаемых пользователю данных

Для оценки этих характеристик используется Django Debug Toolbar

📥📦🗝
Можно зайти на сайт
https://pypi.org
вести надпись Django Debug Toolbar и получить команду для установки этой библиотеки
https://pypi.org/project/django-debug-toolbar/
pip install django-debug-toolbar==4.2.0

Или можно создать файл req.txt (requirements) в корне проекта (где будет папка .venv) и написать
django==4.2.1
ipython==9.15.0
django-debug-toolbar==4.2.0

(django-extensions==3.2.3)

📥📦📦
А потом выполнить команду
pip install -r req.txt

После установки Django Debug Toolbar необходимо его привязать к сайту
В этом может помочь сайт
https://django-debug-toolbar.readthedocs.io/en/latest/installation.html

По кнопке DJDT справа можно отобразить всю информацию. По вкладке SQL можно перейти и увидеть все обращения к базе
данных и обнаружить повторяющиеся 3 similar queries.
🛠💾❌
Если удалить кусок файла sitewomen\women\templates\women\index.html
...
{{ p.cat.name }}
...
То пропадёт надпись 3 similar queries и это будет говорить об успешной оптимизации и избавления от повторяющихся
обращений

Однако без этого куска {{ p.cat.name }} от файла sitewomen\women\templates\women\index.html
не получится отображать категории, но для оптимизации и реализации такой задачи существуют методы
select_related(key) = загрузка сразу всех связанных данных по вненему ключу с типом ForeignKey
prefetch_related(key) = загрузка сразу всех связанных данных по внешнему ключу с типом ManyToManyField

💾🛠
Был изменён sitewomen/women/views.py
