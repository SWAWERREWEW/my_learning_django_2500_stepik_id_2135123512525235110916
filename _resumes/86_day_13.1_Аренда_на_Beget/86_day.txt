86 day = 13.1 Аренда сервера и домена на Beget

Существуют сервера для публикации в интернет
VPS = Vistual Private Server
VDS = Virtual Dedicated Server
Необходим домен, чтобы вместо рандомных цифр отображалось информативное название, для этого нужно подключить домен к
серверу
На сервере должен быть Ubuntu 22.04 , NGINX , Python , gcc , Postgre , Gunicorn , WSGI

Аренда сервера
https://beget.com

Регистрация → Cloud → Физическое лицо → Ввод данных → Регистрация → Создать → Виртуальный сервер → Минимальный тариф →
X рублей в день → Ubuntu 24.04 → Создать виртуальный сервер
Письмо с данными для доступа
Созданный виртуальный сервер → Домены и поддомены → Регистрация доменов → домен → Продолжить

Либо
https://my.aeza.net/home

покупка и настройка домена
https://cp.beget.com/domains

Либо бесплатный домен от сайта
https://freedns.afraid.org/
FreeDNS → Registry → Любой домен → Type: A, subdomen: любое имя, Destination: YourIpServer → Сохранить
(Главное, чтобы домен был без нижнего подчёркивания _ )
В разделе subdomains появляется домен.
Его нужно проверить на сайте DNSCHECKER (должны быть почти везде ✅ зелёные галочки)
https://dnschecker.org/

При регистрации домена стоит указывать реальные сведенья для предотвращения юридических проблем.

Подключение домена к серверу
Домен → Правая кнопка мыши или shift + f10 → Редактировать DNS → A → ip_адрес_сервера
Обновление ip_адреса для домена происходит от 15 минут до 24 часов
Проверка домена
cmd
ping domen.ru
Должны быть отправлены и получены все 4 пакета
