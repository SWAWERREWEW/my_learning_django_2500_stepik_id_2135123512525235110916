В таблице колонки это поля, а строки это записи📝

ORM (Object-Relational Mapping) = Универсальный код для этих баз данных или WSGI приложение💾🚀📦

В файле sitewomen/sitewomen/settings.py

...
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
...

Эти строки означают, что Django взаимодействует с базами данных с расширением sqlite3💾📊🔍, а базой данных по
умолчанию был файл db.sqlite3 ⚙

Рекомендуется скачать SQLiteStudio
