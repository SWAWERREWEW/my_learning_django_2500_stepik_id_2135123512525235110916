def about(request):
    if request.method == "POST":
        form = UploadFileForm(request.POST, request.FILES)
        if form.is_valid():
            # Передаётся атрибут из класса UploadFileForm
            handle_uploaded_file(form.cleaned_data['file'])
        # handle_uploaded_file(request.FILES["file_upload"])
    else:
        form = UploadFileForm()
    return render(request, 'women/about.html',
        {'title': 'О сайте 🔍', 'menu': menu, 'form': form})

При повторной отправке файла, файл будет пересоздан в папке для избежания дубликатов.
В качестве домашнего задания необходимо реализовать возможность сохранять дубликаты с переименованием, но в целом это
будет на следующем занятии.

Существуют различные формы для загрузки данных.
FileField для загрузки файлов
ImageField для загрузки только изображений

📥📦➕
Для работы ImageField необходимо уставновить библиотеку pillow==10.0.0
Которая создана для работы с изображениями
pip install pillow==10.0.0
