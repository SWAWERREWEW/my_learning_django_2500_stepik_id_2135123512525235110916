78 day = 11.2 Подключаем PostgreSQL к проекту

Текущая база данных в файле db.sqlite3 не подходит для больших данных

Нужно установить программу PostgreSQL
https://www.postgresql.org
→ Download → Windows → Download the installer → Любая пред-предпоследняя версия.

Установить СУБД PostgreSQL на компьютер
Установка стандартная с портом 5432 и любым паролем (его лучше записать в папку с программой)
Закрыть мастер Stack Builder
Открыть приложение pgAdmin 4

Создать для этой СУБД базу данных и пользователя-администратора.

📶
После запуска в программе была нажата открыта папка Servers и введён установленный пароль от программы
PostgreSQL → Login/Group Roles → Правая кнопка мыши → Create → Login Group Role...
General: Ввод имени (например sitewomen_user)
Definition: Ещё один пароль
Privileges: Все галочки ✅
→ Save

PostgreSQL → Databases (1) → Правая кнопка мыши → Create → Database...
General: имя
Owner: Ввод имени созданного пользователя (sitewomen_user)
→ Save
