72 day = 9.14 Разрешения и группы (Permissions & Groups)

В django есть группы и права. При редактировании любого пользователя можно просмотреть его права для каждой таблицы в
админ панели. Можно запретить пользователю менять любые таблицы базы данных, однако нужен функционал ограничивающий
форму редактирования.

🌎🔍📖
Документация
https://docs.djangoproject.com/en/4.2/topics/auth/default/#permissions-and-authorization

Для проверки был зарегистрирован новый пользователь kikidon
и был ещё один зарегистрированный новый пользователь employee
Открыта админ панель
Перенесена строчка из таблицы Доступные права в таблицу Выбранные права
women | Известные женщины | Can add Известная женщина
Сохранить
Однако это не ограничит для этого пользователя bez_prav пользование формой редактирования и поэтому нужен класс для
установки прав пользования и указать требуемые разрешения
Синтаксис
permission_required = 'приложение.действие_таблица'

Можно выполнить подобные действия через команды в консоли django
python manage.py shell

myuser.groups.set([group_list])
myuser.groups.add(group, group, ...)
myuser.groups.remove(group, group, ...)
myuser.groups.clear()
myuser.user_permissions.set([permission_list])
myuser.user_permissions.add(permission, permission, ...)
myuser.user_permissions.remove(permission, permission, ...)
myuser.user_permissions.clear()
myuser.has_perm(permission)

Пример
Импортирование модели
from users.models import User
Создание переменной с пользователем
employee = User.objects.get(username='employee')
Просмотр текущих прав
employee.user_permissions.all()
Просмотр групп, в которые входит пользователь
employee.groups.all()
Проверка права у пользователя
employee.has_perm('women.add_women')

Можно открыть базу данных и найти таблицу auth_permission, то можно найти все возможные разрешения для пользователей и
их идентификаторы, которые можно указать при добавлении

Можно добавить разрешение по идентификатору 1
user1.user_permissions.add(1)

Можно поместить выбранное разрешение в переменную

from django.contrib.auth.models import Permission
p = Permission.objects.get(codename='add_category')
user1.user_permissions.add(p)

В базе данных хранится и таблица auth_group со всеми группами

Можно группу поместить в переменную
from django.contrib.auth.models import Group
grup = Group.objects.get(name='moderator_for_women_table')
employee.groups.add(grup)

Для удаления используется метод remove(permission, permission, ...)
Для очищения, опустошения или удаления сразу всего метод clear()

Можно создать собственное разрешение

Например

выбрать объект для настройки доступа
from django.contrib.auth.models import Permission
from django.contrib.contenttypes.models import ContentType
content_type = ContentType.objects.get_for_model(User)

И создать разрешение под названием social_auth
permission = Permission.objects.create(codename="social_auth", name="Social Auth", content_type=content_type)
