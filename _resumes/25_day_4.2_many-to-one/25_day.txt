25 day = 4.2 Создание связи many-to-one многие к одному

📝📊💾
Необходимо создать вторую таблицу и связать с первой

women
id, title, content, slug, time_create, time_update, is_published,
cat_id: Integer, foreign key (Внешний ключ) = id из таблицы category

category
id,
name: VarChar
slug: VarChar

ForeignKey:
to = ссылка или строка класса модели, с которой происходит связывание (в нашем случае это класс Category - модели для
категорий)
on_delete = тип ограничения при удалении внешней записи (в нашем примере это удаление из таблицы Category (первичная
модель)) Задание поведения записей при удалении записи одной таблицы

models.CASCADE = при удалении записи из первичной модели (у нас это таблица Category) происходит удаление всех записей
из вторичной модели (Women), связанных с удаляемой категорией.

models.PROTECT = запрещает удаление записи из первичной модели, если она используется во вторичной (выдаёт исключение)

models.SET_NULL = при удалении записи первичной модели устанавливает значение foreign key в NULL у соответствующих
записей вторичной модели.

models.SET_DEFAULT = при удалении записи первичной модели устанавливает значение foreign key в значение по умолчанию,
которое должно быть определено через класс ForeignKey у соответствующих записей вторичной модели

models.DO_NOTHING = удаление записи в первичной модели не вызывает никаких действий у вторичных моделей.
