Установка библиотек в образ.
Флаг --no-cache-dir позволяет установить библиотеку без дополнительного сохранения в кеше для экономии места

Для скорости лучше прописывать для загрузки отдельные файлы
COPY req.txt .
Вместо загрузки сразу всех файлов
COPY . .

Библиотека tqdm позволяет менять одну строку в выводе

💾🛠
Был изменён файл
# docker/for_first_image.py
import time
import numpy
from tqdm import tqdm

total = 10
iter_tqdm = tqdm(range(total))
for i in iter_tqdm:
    iter_tqdm.set_description(f"x = {i/100}, sin = {numpy.sin(i/100):.4f}")
    time.sleep(1)

🛠💾
Был изменён файл
docker/Dockerfile
FROM python:3.12-alpine
WORKDIR /python-app
COPY req.txt .
RUN pip install --no-cache-dir -r req.txt
COPY Dockerfile .
ENV PYTHONUNBUFFERED=1
COPY for_first_image.py .
CMD ["python", "for_first_image.py"]

tqdm

🛠💾🚀📊
Существует возможность вносить изменения даже в работающий контейнер, которые в нём сохранятся
docker exec first_container pip install matplotlib

💼➕🛠💾📦
На основе нового контейнера можно создать новый образ
docker commit first_container second_image:0.3

Можно очистить только неиспользуемый кеш
docker builder prune

Можно очистить от лишнего вообще все данные: остановленные контейнеры, неиспользуемые образы, неиспользуемый кеш, все
неиспользуемые сети
docker system prune

Очистка от всего кеша, остановленных контейнеров, неиспользуемых образов и сеьей
docker system prune -a
